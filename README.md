# D&D Builder

Офлайн-конструктор персонажей D&D 5e (редакция 2014) на русском языке.

## Запуск

Откройте `dnd_builder.html` в современном браузере. Установка и сервер не нужны — приложение работает локально.

Данные персонажей хранятся в браузере. На странице «Герои» можно скачать резервную копию всей библиотеки и восстановить её из JSON; импорт резервной копии заменяет текущую библиотеку после подтверждения.

## Проверки

Запустите регрессионные тесты расчётов командой `node --test tests/rules.test.cjs` (Node.js, без сторонних зависимостей).

## Источники данных

В приложении есть материалы SRD 5.1, PHB и «Котла Таши», а также данные заклинаний из нескольких источников. Состав и незакрытые вопросы по происхождению описаны в [CONTENT_SOURCES.md](CONTENT_SOURCES.md); не весь контент подтверждён как SRD.
