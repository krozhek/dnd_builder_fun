# D&D Builder

Офлайн-конструктор персонажей D&D 5e (редакция 2014) на русском языке.

## Запуск

Откройте `dnd_builder.html` в современном браузере. Установка и сервер не нужны — приложение работает локально. На вкладке «Лист» можно выбрать оформление 2014 или 2024; расчёты персонажа остаются по правилам 2014 года.

Данные персонажей хранятся в браузере. На странице «Герои» можно скачать резервную копию всей библиотеки и восстановить её из JSON; импорт резервной копии заменяет текущую библиотеку после подтверждения.

Оба оформления листа печатаются в четырёхстраничном формате A4. Поля, которых нет в модели персонажа (например, возраст и внешность), оставлены пустыми для ручного заполнения.

## Проверки

Запустите регрессионные тесты расчётов командой `node --test tests/rules.test.cjs` (Node.js, без сторонних зависимостей). Сводку источников можно получить командой `node scripts/audit-content-sources.cjs`.

## Исходники и сборка

Пользовательская версия остаётся одним автономным файлом `dnd_builder.html`. Исходники разнесены по `src/`: шаблон, стили, игровые данные, ядро и интерфейс. После правок пересоберите HTML командой `node scripts/build.cjs`; тесты проверяют, что готовый файл соответствует исходникам.

## Источники данных

В приложении есть материалы SRD 5.1, PHB, «Котла Таши» и AAG, а также данные заклинаний из нескольких источников. Состав и незакрытые вопросы по происхождению описаны в [CONTENT_SOURCES.md](CONTENT_SOURCES.md); не весь контент подтверждён как SRD.
